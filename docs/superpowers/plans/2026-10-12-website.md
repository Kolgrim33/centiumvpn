# Centium website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Centium download page on Firebase Hosting with a private, rules-locked Firestore click counter.

**Architecture:** Plain HTML/CSS/JS in `website/public/`, no build step. The page reads the latest GitHub release for the APK URL and SHA-256; on Download click it sends `increment(1)` to `stats/downloads` (best effort, short timeout) and then navigates. Firestore rules permit only +1 updates on that one doc.

**Tech Stack:** Firebase Hosting + Firestore (Spark), Firebase JS SDK 11.x modular from gstatic, `@firebase/rules-unit-testing` + Firestore emulator for rule tests, Node 22.

**Spec:** `docs/superpowers/specs/2026-10-12-website-design.md`

## Global Constraints

- No download count shown on the page; no analytics, no cookies, nothing about visitors stored.
- Colours from `android/app/src/main/res/values{,-night}/colors.xml` as CSS variables; light + dark (`prefers-color-scheme`).
- Overpass self-hosted (converted from the app's TTFs); no Google Fonts.
- Sentence case, plain language; no ALL-CAPS labels.
- Download button `href` defaults to `https://github.com/Kolgrim33/centiumvpn/releases/latest`.
- Separate Firebase project from Moro; hosting site `centium` if free.

## Review Focus

- GitHub API down / rate-limited (60/h/IP): button keeps the releases/latest href, version + checksum lines hide. → Task 2 manual check with the API blocked.
- Firestore unreachable or slow (adblock, offline): download still starts within ~800 ms. → Task 2 check with gstatic/firestore blocked.
- Counter doc missing before seeding: increment fails silently, download proceeds. → covered by the same timeout path; Task 3 seeds the doc.
- Rules bypass attempts (+2, set, extra fields, create, delete, read). → Task 1 tests.
- Phone width 360px: no horizontal scroll, route line wraps/scales. → Task 2 check.

### Task 1: Firebase config and locked-down counter rules

**Files:**
- Create: `website/firebase.json`, `website/firestore.rules`, `website/package.json`, `website/test/rules.test.mjs`, `website/.gitignore`

**Interfaces:**
- Produces: Firestore doc `stats/downloads` `{ count: int }`; npm scripts `test:rules`, `downloads`.

- [ ] **Step 1: Write rules tests** (`node --test` + `@firebase/rules-unit-testing`): seed `{count: 5}` with rules disabled, then as unauthenticated: `updateDoc({count: increment(1)})` succeeds; `{count: 7}`, `{count: 4}`, `{count: 6, x: 1}`, `setDoc` on new doc, `deleteDoc`, `getDoc` on `stats/downloads`, and write to `other/doc` all fail.
- [ ] **Step 2: Run** `npm run test:rules` (wraps `firebase emulators:exec --only firestore`) → expected FAIL with default-deny rules on the increment case.
- [ ] **Step 3: Write `firestore.rules`**: only `match /stats/downloads { allow update: if request.resource.data.keys().hasOnly(['count']) && request.resource.data.count == resource.data.count + 1; }`.
- [ ] **Step 4: Run** `npm run test:rules` → all pass.
- [ ] **Step 5: Commit.**

**Interfaces:**

- [ ] **Step 1: Page content**: hero (mark, "Centium", tagline from `short_description.txt`), route line SVG phone → guard → middle → exit → internet, Download button + version line + "SHA-256: …" line, "What you get" and "Good to know" from `full_description.txt`, install steps, footer links (source, changelog, GPL-3.0).
- [ ] **Step 2: `app.js`**: `loadLatest()` fetches the releases/latest API, finds asset matching `/^centium-.*\.apk$/`, sets href, version text, digest text; on failure leaves defaults and hides the version/checksum lines. `onDownload(e)`: `preventDefault`, race `updateDoc(doc(db,'stats','downloads'),{count: increment(1)})` against an 800 ms timeout, then `location.href = href`. - [ ] **Step 3: Verify locally** with `firebase emulators:start --only hosting,firestore`: click → emulator count +1; block api.github.com → button still links to releases/latest; block firestore → download still starts; 360px width no horizontal scroll; dark mode readable.
